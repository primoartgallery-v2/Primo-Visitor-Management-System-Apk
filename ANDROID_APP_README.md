## 🖼️ Screenshots Ke Mutabiq Shamil Features

### 1. 📊 Live Dashboard & Analytics (Screenshot 3)
* **Brand Header:** Primo Art Gallery "P" circular monogram + "VISITOR MANAGEMENT DASHBOARD" + Green `● LIVE DATA` badge + Quick `Scan Visitor` button.
* **Current Exhibition Switcher:** Dropdown jisme aap easily switch kar sakte hain:
  - *DRISHTI – A Legacy of Masters* (Living Traditions Centre, Bikaner House)
  - *The Emerging Perspectives — Group Art Exhibition* (India Habitat Centre)
  - Ya koi bhi nayi added exhibition!
* **4 Big Metric Cards:**
  1. `TOTAL VISITORS` (Registered visitors count)
  2. `CHECKED IN` (Visitors entered count)
  3. `PENDING` (Not checked in count)
  4. `CHECK-IN RATE` (% overall attendance)
* **Attendance Progress Bar:** Real-time visual progress bar + `Refresh` button + `Open Scanner` button.
* **Latest Check-ins Live Feed:** Real-time stream of latest entered visitors.

---

### 2. 👥 Visitors Directory & Search (Screenshot 1 & 3)
* **Search Bar:** Name, Phone Number, Email ya Visitor ID (`PAG-2026-XXXX`) se instant search.
* **Filter Tabs:** All / Checked In / Pending.
* **Visitor Cards:** Har visitor ka Name, ID, Phone, City, Status, aur direct `Check In Now` button.

### 4. 📷 Full Camera QR Scanner
* One-tap access via bottom navigation ya topbar `Scan Visitor` button.
* High-speed CameraX QR detection with animated gold laser.
* Flash/Torch toggle button (`💡`).
* Audio beep sound + haptic vibration feedback.
* Instant visitor verification card popup.
